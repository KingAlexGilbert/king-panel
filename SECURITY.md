\# Security Policy



\## Reporting Security Issues



If you find a security issue related to King Pong, please report it through the GitHub Issues page.



When reporting a security issue, please include:



* A clear description of the issue
* Steps to reproduce it
* What version of King Panel you tested
* Any relevant screenshots, logs, or other details



\## Supported Versions



The latest public release is the main supported version of King Pong.



Older versions are preserved for project history and may not receive fixes.



\## Security Notes



King Panel runs locally on your computer and does not send your display information or settings to external servers.



The Windows installer is currently unsigned. Because of this, Windows may display an Unknown Publisher or Microsoft Defender SmartScreen warning when installing King Panel.



Always download King Panel from the official GitHub repository or its official Releases page.
